# Paper prompt transcriptions

These files are faithful, line-normalized transcriptions of Figures 6–9 from
Li et al., *CODESKILL*, arXiv:2605.25430v1, pages 16–19. They intentionally
retain the paper's bash-agent wording and schemas. Runtime adaptations belong
only in `prompts/runtime/` or `prompts/custom/` and name their deltas.
